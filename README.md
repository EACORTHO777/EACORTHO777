## Featured projects

### [Hemmaplanen](https://github.com/EACORTHO777/Hemmaplanen)
A household app my family uses every day: shopping list, calendar, to-dos and a medicine log that reminds us when the next dose can be given. Installable on the phone as a PWA, with live sync between phones and push notifications.

- Postgres with Row Level Security, so each household only ever sees its own data, and dose rules enforced by database triggers
- Express API for push notifications, with helmet, rate limiting and token checks
- Unit, API, database (pgTAP) and Playwright end-to-end tests, all required in CI before merging
- Accessibility 100 in Lighthouse, health data kept in the EU, error tracking with no personal data

React · TypeScript · Supabase (PostgreSQL) · Express · Playwright · Docker + Caddy · GitHub Actions · Sentry · [Live demo](https://hemmaplanen.vercel.app) (press "Prova demo")

### [StudyPal](https://github.com/EACORTHO777/studypal)
A study session tracker with a REST API, JWT authentication, and a dashboard showing study time per day and per course.

Node.js · Express · MongoDB · Jest · Docker · GitHub Actions · [Live demo](https://studypal-dpft.onrender.com/)

### [BIK Bötesystem](https://github.com/EACORTHO777/boetesystem)
A real-time fines tracker for my football team, used during the season. Fines, payments and the team fund sync live across everyone's phones.

Vanilla JavaScript · Cloud Firestore · Netlify
